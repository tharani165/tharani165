# 💫 About Me

Hi, I'm **Tharani Ravi**, a final-year **Electronics & Communication Engineering** graduate with a strong passion for **Data Engineering, Python Development, Artificial Intelligence, and Analytics**.

My journey started with embedded systems and IoT, where I built robotics and automation projects using Raspberry Pi, ESP32, and Arduino. As I explored software development, I discovered a deep interest in designing scalable data pipelines, backend systems, and analytics solutions using Python.

Currently, I'm working as a **Data Analytics & Python Developer Intern** at **Kaar Technologies**, where I contribute to building production-style data engineering pipelines for macroeconomic datasets. My work involves API integration, ETL development, workflow orchestration, PostgreSQL, Docker, and analytics.

Alongside data engineering, I enjoy building AI-powered applications using Computer Vision and Machine Learning to solve practical problems in healthcare, transportation, and automation.

I believe good engineering is about writing reliable, maintainable, and scalable software that creates real-world impact.
